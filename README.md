# morse-band
![image on arm](https://rawcdn.githack.com/KOEGlike/morse-band/10ea6d376f088f068a7faa55c1b2209cb9f8524f/images/morse-band.jpg)
A pair or multiple pairs of bands, if you press the button all the other bands will vibrate, range is up to 320m

It will use esp-now for communications, and a lipo battery is a power source managed by the xiao
