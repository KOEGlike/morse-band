# Morse Band
<img src="https://rawcdn.githack.com/KOEGlike/morse-band/10ea6d376f088f068a7faa55c1b2209cb9f8524f/images/morse-band.jpg" height="500">
A pair or multiple pairs of bands, if you press the button on one of them, all the other bands will vibrate, range is up to 320m.
It uses esp-now for communications, and a lipo battery is a power source managed by the xiao.
It uses a linerar low profile keyboard switch for the button.
